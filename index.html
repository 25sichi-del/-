Головна Основи Курси Інструменти

Вітаємо на Порталі Навчальних Ресурсів!

Цей сайт розроблено в рамках лабораторної роботи №2 (Варіант №23). Тут зібрано найкращі джерела знань для студентів напрямку «Вебтехнології та вебдизайн».

1. Довідники з основ веб-розробки (HTML, CSS, JS)

  • MDN Web Docs — Найповніша офіційна документація з веб-технологій від Mozilla.
  • W3Schools — Інтерактивні туторіали з прикладами та онлайн-редактором коду.
  • Сучасний підручник JavaScript — Детальний курс з мови програмування JS українською мовою.

2. Онлайн-платформи навчальних курсів

  • Prometheus — Провідна українська платформа безкоштовних онлайн-курсів.
  • Coursera — Курси від провідних світових університетів та IT-компаній.
  • edX — Навчальні програми з програмування від MIT та Harvard.

3. Корисні інструменти розробника

Необхідний софт для комфортного написання та публікації коду:

  • VSCodium / VS Code — Зручний редактор коду з підтримкою розширень.
  • GitHub — Платформа хостингу коду та системи контролю версій Git.
  • Figma — Інструмент для проектування веб-дизайну та макетів інтерфейсу.
